01 / THE PROBLEM

Five failures

01

The interface reads as AI

Indigo gradients, Inter at weight 700, three identical cards, a badge on everything. Competent and interchangeable.

02

The agent has no taste

Nothing is wrong and nothing is decided. Every spacing a multiple of 4, every heading weight 700.

03

Dashboards bury the decision

Charts nobody reads, KPIs stripped of context, real-time updates that move without meaning.

04

Nobody checks the details

The hero looks great and the button has no focus state. The empty state is a blank screen.

05

You can't tell when it's done

An agent that never stops polishing burns your time; an agent that stops early ships broken states.
