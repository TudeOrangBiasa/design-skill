# Design resources

Real products beat hand-rolled substitutes. Use these sources for icons, illustrations, backgrounds, gradients, components, avatars, and shapes instead of inventing them or falling back to CSS-only placeholders. Each entry is a trusted source from the collection this skill maintains.

## Icons and illustrations
- [Iconoir](https://iconoir.com/): a consistent stroke icon set.
- [Humbleicons](https://www.humbleicons.com/): free icons for UI.
- [Flowbite icons](https://flowbite.com/icons/): SVG icon library.
- [OpenMoji](https://openmoji.org/): open emoji glyphs for expressive content, never as UI icons.
- [Khushmeen doodle icons](https://khushmeen.com/icons.html): hand-drawn style icons.
- [Koboyo](https://koboyo.com/icons): icon collection.
- [Humaaans](https://www.humaaans.com/): mix-and-match human illustrations.
- [Open Doodles](https://opendoodles.com/): hand-drawn illustrations.

## Backgrounds
- [Backgrounds Supply](https://backgrounds.supply/freebies): free aesthetic backgrounds and wallpapers.
- [FluidShader](https://fluidshader.vercel.app/): WebGL fluid gradient editor.
- [Paper Shaders](https://shaders.paper.design/): zero-dependency shader backgrounds.

## Gradient makers
- [ColorFlow](https://colorflow.ls.graphics/): mesh gradient generator.

## UI components
- [beUI](https://beui.dev/docs/ai-agents), [Chánh Đại components](https://chanhdai.com/components), [unlumen UI](https://ui.unlumen.com/components), [Lightswind](https://lightswind.com/components), [OriginKit](https://www.originkit.dev/), [Toolcraft](https://toolcraft.sh/), [Astryx](https://astryx.atmeta.com/), [shieldcn](https://shieldcn.dev/), [UX Components](https://ux-components.com/), [OpenUI](https://www.openui.com/), [HeroUI](https://heroui.com/).

## SVG shapes
- [Shapes Gallery](https://www.shapes.gallery/): SVG shape collection.

## Rules

- **Icons come from a real product.** Pick one set (Iconoir, Humbleicons, Flowbite) and use it consistently. Never mix sets. Never use emoji as UI icons; OpenMoji is for expressive content only.
- **Illustrations come from a real source.** Humaaans, Open Doodles, or an authored set. Never shape-assembled SVG scenes standing in for pictures.
- **Backgrounds come from real material.** A background from Backgrounds Supply, a shader from Paper Shaders, or the subject's own world. A CSS-only gradient wash is a fallback of last resort, not a default.
- **Components come from the ecosystem.** When the project has no component library, pull from the UI component list instead of hand-rolling everything.
- **Verify the URL before referencing it.** Dead asset links ship as broken images.
